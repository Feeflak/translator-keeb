# Translator

### Ergonomic Keyboard with an Integrated Mouse Sensor

## [3D print files]()

## Translator XV COMING SOON

- Invisible bottom cover

- MCU specific mounting brackets

- Improved TRRS socket mount

## Features

- 36 keys

- split

- integrated mouse sensor for each half

- Keywell

- 3 thumb cluster keys

- high(~45deg) flare/tent angle

- fully opensource

- wired

## BOM

- 36 x mx switches

- 36 x 1n148 diodes

- 2 x 3d printed case(about 200g of filament and 5hours per half)

- ~1m of 1.2 mm copper wire

- heat shrink tubing

- 28AWG soldering wires

- 2 x PMW3360 mouse sensor boards

- 2 x qmk compatible 3.3V mcu with at least 15 gpio pins and usbc - like RP2040 Zero

- Standard soldering equipment([guide](https://www.youtube.com/watch?v=hjml-K-pV4E))

## Recommended Print Settings

- 0.2mm layer height - the lower the better for layer line visibility, but increases print time

- 0.4mm nozzle - the lower the better for layer line visibility, but increases print time

- Auto generated tree supports

- Mat pla- good for sanding and looks great as it is + plenty strong + cheap

- for better adhesion apply glue on the build plate - especially for pla
